# Решение

- Бэкенд — Node.js/HTTP API, СУБД PostgreSQL, очередь уведомлений на Redis.
- Фронтенд диспетчера — SPA; мобильный кабинет мастера — PWA.
- Аутентификация — LDAP-коннектор к Active Directory заказчика.
- Развёртывание — Docker Compose в контуре заказчика (РФ), наружу только исходящие.
- Уведомления — воркер, читающий очередь Redis, и WebSocket-канал для диспетчера.
