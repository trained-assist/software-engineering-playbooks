# Факты

- Заказчик — сеть из 40 автосервисов, ведёт заявки на ремонт в таблицах Excel.
- Сейчас заявка живёт в почте и в чате мастера; единого учёта нет.
- Есть 3 филиала с собственными диспетчерами; каждый ведёт свои заявки.
- Аккаунты мастеров и диспетчеров уже есть в Active Directory заказчика.
- Заявки нужно принимать круглосуточно; в пик — до 300 заявок в час.
- По 152-ФЗ персональные данные клиентов должны храниться на серверах в РФ.
